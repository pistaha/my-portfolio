# Собственная аналитика портфолио

Сайт остаётся на GitHub Pages. Этот Cloudflare Worker принимает события кликов, хранит только название события, ID дизайн-проекта и время. IP-адреса, cookies, user-agent и персональные данные не сохраняются.

## Развёртывание API

Нужны аккаунт Cloudflare и Wrangler (`npm install -g wrangler`). Из этой папки:

API уже развернут: `https://pistaha-portfolio-analytics.pistaha-analytics.workers.dev`. База D1 создана, схема применена, секрет `ANALYTICS_ADMIN_TOKEN` настроен. Повторное развёртывание из этой папки выполняется командой `npx wrangler deploy`.

Адрес API также записан в `Projects/client-lab2/config/_default/params.toml`. После изменения сайта пересобери его из корня репозитория (`hugo -s Projects/client-lab2`) и опубликуй обновлённый статический сайт.

Страница статистики будет доступна по адресу `https://pistaha.github.io/my-portfolio/analytics/`. Введённый токен хранится только в поле формы и не сохраняется в браузере.

## Что записывается

- `home` — клик по ссылке на главную;
- `projects` — клик по ссылке на список проектов;
- `design_collection` — клик по карточке «Дизайн-проекты»;
- `design_item` — клик по карточке конкретного дизайн-проекта или переход к кейсу Energy Training Hall.

Счётчик считает нажатия, а не прямые заходы по URL. В панели показываются события только за текущий день по московскому времени. В 00:00 МСК Worker очищает предыдущие события; расписание задано на 21:00 UTC. Старые записи также удаляются при первом запросе статистики или событии после полуночи.
