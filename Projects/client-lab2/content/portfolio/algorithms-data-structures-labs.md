## Коротко о проекте

**Algorithms & Data Structures Labs** — отдельный репозиторий с лабораторными работами по алгоритмам и структурам данных. Код организован по веткам: каждая ветка хранит самостоятельный C#-проект, README и исходное задание.

[Исходный код на GitHub](https://github.com/pistaha/algorithms-data-structures-labs/tree/main)

## Что внутри

- `lab1`: List ADT, двусвязный список, cursor-based list и удаление дубликатов;
- `lab2`: Stack, Queue и Map ADT с массивной и связной реализацией;
- `lab3`: Dictionary ADT, открытое и закрытое хеширование, linear probing;
- `lab4`: топологическая сортировка, проверка частичного порядка и поиск циклов;
- `lab5`: multilist для моделирования связи многие-ко-многим через хеширование и кольцевые списки.

## Технический фокус

Проект показывает ручную реализацию классических структур данных без опоры на готовые коллекции. В работах явно разобраны хранение в массивах, ссылочные структуры, позиции, коллизии, хеш-таблицы, обход связей и детерминированный консольный вывод для проверки поведения.

## Стек

- C#;
- .NET 8 / .NET 10;
- консольные приложения;
- Git-ветки как отдельные снимки лабораторных проектов.

## Запуск

```bash
git clone https://github.com/pistaha/algorithms-data-structures-labs.git
cd algorithms-data-structures-labs
git switch lab3
dotnet run --project "algo3/algo3.csproj"
```

## Результат

Репозиторий дополняет портфолио отдельным направлением по фундаментальным структурам данных: от линейных ADT до хеширования, графовых зависимостей и многосвязных отношений.
