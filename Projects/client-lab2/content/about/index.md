Я студент и разработчик. Собираю веб-приложения и backend-системы целиком: проектирую структуру, пишу интерфейс и API, подключаю базу данных, тесты, контейнеры и инфраструктуру.

## Что для меня важно
- **Работающий результат**: проект должен запускаться воспроизводимо и решать заявленный сценарий.
- **Системное мышление**: ясные границы модулей, переиспользуемые компоненты и проверяемые контракты.
- **Инженерная прозрачность**: документация, тесты, миграции и честное описание текущего статуса.

## Инструменты и навыки
- Vue 3, Vite, JavaScript и адаптивные интерфейсы
- Python, FastAPI, REST API и SQLite
- C#, ASP.NET Core, PostgreSQL и многослойная архитектура
- Docker, Docker Compose, Nginx, CI/CD и наблюдаемость
- Git, GitHub, автоматические тесты и техническая документация
